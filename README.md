# EndlessRunnerIPSSI

Endless runner façon Subway Surfers, développé en C# sous Unity dans le cadre de ma formation à l'IPSSI.

## Technologies
- Unity
- C#
- TextMeshPro (UI dynamique)
- PlayerPrefs (sauvegarde des scores)

## Fonctionnalités
- Gameplay type endless runner
- Système de score persistant
